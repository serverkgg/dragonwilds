## Create your server

From the **Create a server** page, pick RuneScape: Dragonwilds, then choose a plan. By Jagex's numbers, the server needs 2GB of RAM plus 1GB for each player, and it holds 6 players at most, so 8GB carries a full server. The details are in the [performance guide](/games/dragonwilds/guides/performance).

After payment, your server starts setting up. Follow its progress on the order page. Once it's ready, your server downloads Dragonwilds from Steam, and it needs one thing from you before it starts: the player ID of its owner.

> [!note] The first start takes a while as the game files download. Watch all of it from the Console tab.

@[open](console)

## Find your player ID {#player-id}

Dragonwilds needs the owner's player ID to start the server, and the owner is the one who can ban and unban any player. Use your own ID, or the ID of the friend who runs the group.

1. Open Dragonwilds on your device
2. Open the **Settings** menu
3. Your player ID is at the bottom of the menu. Copy or type it exactly as it is

## The setup steps

The panel opens the **Setup** page to walk you through a few short steps:

1. The owner's player ID. Paste the ID from the game
2. A check that your server started with that ID
3. The server name, the world name and the world password
4. Crossplay: the platforms players can join from
5. How your friends join

The first two steps can't be skipped, because the server doesn't start without an owner. Press **Skip this step** on any other step you don't need. You'll find each setting later in the **Settings** tab.

@[open](setup)

## Join the game

Players find your server by its world name, which you'll find on the **Overview** page. Then inside Dragonwilds:

1. Open **Worlds**
2. Choose the **Public** tab
3. Type the world name in the search box, then pick your server

> [!note] Capital and small letters in the world name are different, so type it exactly as it is. If you set a world password, Dragonwilds asks every player for it when they join.

Players can also join with the join code or your server's address. The three ways are in the [access guide](/games/dragonwilds/guides/access).

@[open](overview)

> [!warning] A player can join only when their game is on the same version as the server. We update your server on our own after each game update once it is stopped, so remind your friends to update their game too. The details are in the [updates guide](/games/dragonwilds/guides/updates).

## What a Dragonwilds server can't do

None of this is missing from your server. It's missing from Dragonwilds itself:

- **No kick or ban from the panel.** The owner and the admins kick and ban players inside the game. The steps are in the [players guide](/games/dragonwilds/guides/players).
- **No whitelist.** The world password keeps out everyone who doesn't have it.
- **No console commands.** Dragonwilds reads nothing from the console, so the ones we answer there (`status`, `players`, `access`, `help`) are handled by the panel rather than passed to the game.
- **No announcements.** There is no way for the server to put a message in front of players.
- **No UE4SS mods.** Your server runs pak mods only. The details are in the [mods guide](/games/dragonwilds/guides/mods).

## Before you start

- A Dragonwilds server holds 6 players at most
- Players on PC, PlayStation, Xbox and Nintendo Switch 2 play together while crossplay is on, as it is by default
- The server creates a **Standard** world at its first start. For a **Custom** or **Creative** world, create it in your game on PC, then upload it. The steps are in the [worlds guide](/games/dragonwilds/guides/worlds)
- A stop or a restart writes nothing to your world, and it keeps what the game last saved. We also take automatic backups, and you can take one yourself whenever you like
